# Graveyard Party's Supa Game — Profile Page

TG MiniApp profile page built with React + Vite.

## Tech Stack
- React 18
- Vite 6
- CSS Modules

## Features
- Profile header with player stats
- Inventory tab with gift grid (3-column layout)
- Gift selection with multi-select and bottom action bar
- Gift modal (take / sell)
- Referral and Tasks tabs
- Bottom navigation bar
- Chat bubble notification
- Fully responsive for mobile (TG MiniApp viewport)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
